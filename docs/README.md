# Reversi Console (VCL)

Reversi Console (VCL) is one of [Richèl Bilderbeek's games](https://richelbilderbeek.github.io/games/).

A console version of the game Reversi, using the C++ VCL library.

See also [Reversi](https://richelbilderbeek.github.io/reversi/).
